# ✨ Visão Geral

O **Relaxant’s Spa** foi desenvolvido com o objetivo de criar uma experiência visual elegante e agradável, simulando um ambiente real de apresentação institucional.

Além do design moderno, o projeto também busca demonstrar boas práticas de desenvolvimento Front-End, priorizando:

* Componentização
* Responsividade
* Escalabilidade visual
* Organização de código
* UX/UI
* Acessibilidade
* Estrutura semântica

# 🏗️ Arquitetura do Projeto

O projeto foi estruturado buscando organização, reutilização e facilidade de manutenção.

```bash
src/
│
├── components/
├── pages/
├── styles/
├── assets/
├── data/
└── utils/
```

### Estrutura aplicada:

* Separação de responsabilidades
* Componentes reutilizáveis
* Organização escalável
* Facilidade de manutenção
* Melhor legibilidade de código

# 🛠️ Desafios Técnicos

Durante o desenvolvimento, alguns dos principais desafios trabalhados foram:

### Responsividade entre dispositivos

Garantir consistência visual em diferentes resoluções sem comprometer a experiência do usuário.

### Organização da interface

Estruturar componentes de forma reutilizável e escalável, mantendo clareza no código.

### Acessibilidade

Aplicar melhorias para usuários com limitações visuais e auditivas, buscando uma navegação mais inclusiva.

### Compatibilidade

Corrigir inconsistências de renderização entre diferentes dispositivos e navegadores.
